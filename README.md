# Java Calculator

This is a simple calculator I made in Java to practice some of the basics I learned while programming.

The program lets you enter two numbers and choose between addition, subtraction, multiplication, or division. It also lets you perform multiple calculations without restarting the program.

## Features

- Addition, subtraction, multiplication, and division
- Supports decimal numbers
- Checks for division by zero
- Option to perform another calculation
- Handles invalid operation choices

## What I Used

- Java
- Scanner for user input
- Switch statements
- Do-while loops
- If-else statements

## How to Run

1. Make sure Java is installed.
2. Open a terminal in the project folder.
3. Compile the program:

   `javac src/Main.java`

4. Run the program:

   `java -cp src Main`

## About

I made this project on my own to get more comfortable writing Java programs and using loops, conditionals, and user input.
